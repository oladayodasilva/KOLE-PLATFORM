# KÓLÉ Platform

KÓLÉ is a climate infrastructure technology platform that connects waste
collection, community rewards, material traceability, recycling,
manufacturing, and sustainable infrastructure delivery.

## Applications

- `backend` — Spring Boot modular monolith
- `admin` — Next.js operations dashboard
- `apps/customer_app` — Flutter customer application
- `apps/collector_app` — Flutter collector application
- `website` — Public website
- `infrastructure` — Deployment and infrastructure configuration
- `docs` — Product, architecture, engineering, and operations documentation

## Development services

The local environment uses:

- PostgreSQL
- Redis
- MinIO
- Mailpit
- Docker Compose
